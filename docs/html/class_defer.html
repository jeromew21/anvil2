Detailed Description

template<typename F>
class Defer< F >

A utility class that executes a callback when it goes out of scope.

This class is useful for implementing RAII-style deferred execution. The callback is executed unless the Defer object is dismissed.

Template Parameters
FThe type of the callback function.
