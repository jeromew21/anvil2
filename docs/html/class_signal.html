Detailed Description

template<typename... Args>
class Signal< Args >

A signal/slot mechanism for connecting and emitting callbacks.

This class allows you to connect multiple callbacks (slots) that will be invoked when the signal is emitted. It supports variadic arguments for the callbacks.

Template Parameters
ArgsThe types of the arguments passed to the callbacks.
